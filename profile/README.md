### About

Pave Universe is a creative technology company.
We started in 2021 running a single Minecraft server — today we build for creators across game development, virtual avatars, and the platforms that host them.

<br>

### What we build

| Product | Description | Status |
| --- | --- | --- |
| **LUCY STORE** | Marketplace for Minecraft plugins, resource packs, and 3D models | ● Live |
| **LUCY CLOUD** | Managed Minecraft server hosting with a simple control panel | ● Live |
| **Game Development Assets** | Production-ready 3D assets for Unity, Unreal Engine, and Blender | ○ Coming soon |
| **Metaverse Systems** | VRChat avatars, full-body VR tracking, and VTuber models for virtual creators | ○ Coming soon |
