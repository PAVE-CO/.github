# Pave Universe

Pave Universe is a creative technology company building the tools, content, and infrastructure behind connected virtual worlds.

We started in 2021 running a single Minecraft server. Today we build for creators across game development, virtual avatars, and the platforms that host them.

## What we build

**LUCY STORE**\
A marketplace for Minecraft plugins, resource packs, and 3D models.

**LUCY CLOUD**\
Managed Minecraft server hosting with reliable infrastructure and a simple control panel.

**Game Development Assets** — Coming soon\
Production-ready 3D assets for Unity, Unreal Engine, and Blender.

**Metaverse Systems** — Coming soon\
Solutions for virtual creators, including VRChat avatars, full-body VR tracking, and VTuber models.

## Technology

- **Languages** — TypeScript, JavaScript, Python, Java, Kotlin, C#, C++, Go, Rust, Lua
- **Web** — React, Next.js, Node.js, Prisma
- **Data** — PostgreSQL, MySQL, SQLite, Redis, MongoDB
- **Game and 3D** — Unity, Unreal Engine, Blender, Blockbench
- **Minecraft** — PaperMC, SpigotMC, Skript
- **XR** — VRChat, SlimeVR
- **Infrastructure** — Cloudflare, AWS, Oracle Cloud, Vercel

## Our history

- **2021** — Launched LUCY NETWORK, a Minecraft server.
- **2024** — Founded LUCY STUDIO and launched LUCY STORE and LUCY CLOUD.
- **2026** — Became Pave Universe, expanding beyond Minecraft.
