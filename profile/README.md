## 🌌 About

2021년 마인크래프트 서버 **LUCY NETWORK**로 시작해, 2024년 **LUCY STUDIO**를 설립했습니다.
플러그인·리소스팩·3D 모델링 스토어와 서버 호스팅을 운영해 온 경험을 바탕으로,
2026년 **Pave Universe**로 이름을 바꾸고 마인크래프트를 넘어 더 넓은 디지털 세계로 나아가고 있습니다.
